# Habit Tracker Expo

This is the React Native mobile version of the habit tracker screen, built for Expo because you usually work with React Native + Expo. It includes animated water jars, realistic glass styling, wooden shelves, the streak card, banner, progress card, and bottom navigation. [cite:29][cite:27][code_file:26]

## Install

1. Run `npm install`. [code_file:26]
2. Run `npx expo start`. [code_file:26]
3. Open in Expo Go, Android emulator, or iOS simulator. [code_file:26]

## Files

- `App.js` contains the full screen and reusable jar/shelf components in one file for easy editing. [code_file:26]
- `package.json` already includes Expo, `react-native-svg`, `react-native-reanimated`, and `expo-linear-gradient`. [code_file:27]
- `babel.config.js` includes the Reanimated plugin required for the wave animation. [code_file:28]
