# Habby Tracker

A habit tracker with a mascot-driven UI — six mascots with different emotions give feedback on streaks, breaks, and milestones as you build habits.

## Features

- Track daily habits and streaks
- Contextual mascot reactions (celebration, encouragement, streak-break feedback)
- Available as a web app and as an Expo project (`habby/`)

See [MASCOT_INTEGRATION.md](./MASCOT_INTEGRATION.md) for how the mascot system maps app context to emotion.

## Run locally

Open `habit-tracker.html` directly, or for the Expo app:

```bash
cd habby
npm install
npx expo start
```
